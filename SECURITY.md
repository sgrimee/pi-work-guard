# Security policy

## Scope and security model

`pi-work-guard` is a best-effort user-assistance extension. It is not designed to be an unbypassable security boundary or an enterprise policy-enforcement mechanism. See the [README](README.md#privacy-prerequisites-and-limitations) for its configuration, credential-access, network, and workspace-classification limitations.

## Reporting a vulnerability

Please report suspected vulnerabilities privately using the repository's GitHub **Security Advisory** reporting feature. Include:

- affected version and Pi version
- steps to reproduce
- expected and actual behavior
- impact assessment
- a proposed fix or mitigation, if known

Do not include real access tokens, corporate repository URLs, proprietary source code, or personal account data. If private reporting is not enabled for the repository, open a minimal public issue asking maintainers to provide a private contact channel; do not disclose exploit details there.

## Supported versions

Until a stable release is published, only the latest version on the default branch receives fixes.
